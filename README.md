# Anime Info Website

A multi-page informational website about anime, created as the final project of an
HTML/CSS/JavaScript course. The site introduces anime as an art form and covers
audience-based and setting-based genres, the history of anime from the 1900s to the
2000s, major animation studios, interesting facts and a top-10 list of famous titles,
with separate pages dedicated to *Naruto* and *Bungo Stray Dogs*.

The website content is in Russian.

**Context:** final project of the web development course, IT STEP, 2021

## Features
- Animated preloader that redirects to the main page
- Responsive navigation with a side panel and hamburger menu
- Modal windows with genre descriptions (implemented with CSS `:target`)
- Image slider (Swiper) and parallax sections
- Embedded video and links to anime openings
- Separate themed pages for individual anime titles

## Technologies
HTML5, CSS3, JavaScript, jQuery, Swiper, Font Awesome, Hamburgers

## How to run
Open `index.html` in a browser. The preloader redirects to the main page (`site.html`)
after a few seconds.
